当日のテーマ

「誰に、どんな価値を、どう届けて収益につなげるか」

Microsoft 365 Copilot との連携や、販売・取引の窓口となる Microsoft Marketplace を通じて、貴社のサービスをどう広げるかを考える場です。出品手順の説明にとどまらず、貴社のサービスを題材に、次の点を具体化します。

  • 顧客と提供価値どの企業・部門の、どんな課題を解決するか
  • 事業化の進め方無償連携で利用を広げるか、有料サービスとして展開するか、その組み合わせか
  • 販路と次の一歩既存営業、Marketplace、販売パートナーをどう活用するか

当日は、貴社の事業仮説と、社内で確認すべき事項・担当者・次のアクションを整理してお持ち帰りいただきます。Marketplace への公開経験がなくてもご参加いただけます。

先行事例

実際に、自社のデータを AI エージェントとして Microsoft 365 Copilot に載せ、それを入口に大手企業との接点を広げている企業が出始めています。当日はその事例を取り上げ、公開までの道筋と、公開後に何が起きたかを共有します。

ご参加後の支援

Microsoft が実行する支援

準備が整った企業から順に、4 週間の集中支援

Microsoft の担当チームが 4 週間集中して伴走し、「いつでも公開申請できる状態」と「最初のパイロット先・開始時期」を一緒に決めます。その後の約 1 か月で、申請・審査・公開まで伴走します。

  • 第 1 週ソリューション設計のワークショップ
  • 第 2〜3 週実装・テスト（オンラインの Q&A で支援）
  • 第 4 週公開申請できる状態の確認。最初のパイロット先・開始時期の決定
  • その後 約 1 か月申請・審査・公開までの伴走

Partner Center の登録がまだでも、並行して進められます。対象は Copilot 向けの Agent・Connector・Cowork plugin・Work IQ API 連携を開発する企業で、1 社以上でのパイロット実施と事例化を前提とします。

調整のうえ順次ご案内する機会

公開とパイロットの準備が整ったサービスに

  • 想定顧客を担当する Microsoft 営業へのご紹介
  • Microsoft 主催の 業界・製品イベントでの発信機会
  • 販売パートナーとの接続

いずれも相手側との調整を経て、準備の整ったサービスから順にご案内します。
