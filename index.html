希望する企業向けの
個別支援

イベントへの参加とは別に、
ご希望を伺います。

準備が整った企業から順に、Microsoft の担当チームが設計・実装・公開申請の準備を支援します。開始時に4週間の到達点と、公開申請の目安時期を相談します。

4週間で、公開申請できる状態を目指します。

実装とテストを進めながら、最初のパイロット先と開始時期を相談します。続く約1か月は、申請・審査・公開に向けた対応を支援します。公開時期は、審査などの状況によって前後します。

集中支援の対象と条件

Copilot 向けのエージェント、コネクター、Cowork plugin、Work IQ API 連携を開発する企業が対象です。1社以上でのパイロット実施と事例化を前提とします。

集中支援の進め方を見る
  1. 第1週ソリューション設計のワークショップ
  2. 第2〜3週実装・テスト。オンラインの Q&A で支援します。
  3. 第4週公開申請の準備状況を確認し、最初のパイロット先と開始時期を相談します。
  4. その後、約1か月申請・審査・公開に向けた対応を支援します。

Partner Center の登録がまだの場合は、支援と並行して進められます。

営業・販売パートナーへのご紹介について

公開とパイロットの準備が整ったサービスには、想定顧客を担当する Microsoft 営業や販売パートナーへのご紹介、Microsoft 主催の業界・製品イベントでの発信機会も、調整のうえ順次ご案内します。

いずれも相手先との調整が必要です。ご案内できる内容は、サービスや準備状況によって異なります。

よくあるご質問

Marketplace への公開経験や、Partner Center の登録がなくても参加できますか？
ご参加いただけます。Partner Center の登録は、参加後の集中支援と並行して進めることもできます。
サービスが AWS や Google Cloud 上で動いていても、参加できますか？
本イベントにはご参加いただけます。Marketplace への公開・販売や各支援制度の適用条件は、サービスの構成・提供方法に応じて確認します。
顧客ごとの個別見積もりでも、Marketplace で販売できますか？
Private Offer を利用すると、顧客ごとの価格・取引条件を設定できます。詳しくは、当日の「公開・販売に向けた準備」でご紹介します。
参加後の個別支援は必須ですか？
個別支援や集中支援への参加は任意です。当日は、事業仮説シートを使ったワークにご参加いただきます。
参加費や支援費はかかりますか？
イベントへの参加と、参加後にご案内する支援は無料です。開発・運用に利用するサービスの料金は、各サービスの条件をご確認ください。
